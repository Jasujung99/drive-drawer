# Practical prompts / 바로 쓰는 요청 문구

Replace the folder names with your own. Each prompt works on its own; the skill asks for anything missing.

## 1. A new drawer / 새 서랍 만들기

**English**

```text
Set up Drive Drawer for me. Use a new folder called "Drawer" in my Google Drive, show it in English, and walk me through the Apps Script steps one at a time.
```

**한국어**

```text
드라이브 서랍을 만들어 줘. 내 Google Drive에 "서랍"이라는 새 폴더를 쓰고, 화면은 한국어로 해 줘. Apps Script 단계는 하나씩 안내해 줘.
```

## 2. My AI chat archive on my phone / AI 대화 아카이브를 휴대폰에서

**English**

```text
I archived my ChatGPT and Claude chats with AI Chat Archive into the "AI archive" folder in my Drive. Make that folder readable on my phone with Drive Drawer. Don't move or rename anything in it.
```

**한국어**

```text
AI Chat Archive로 정리한 ChatGPT·Claude 대화가 내 Drive의 "AI 아카이브" 폴더에 있어. 이 폴더를 드라이브 서랍으로 휴대폰에서 볼 수 있게 해 줘. 폴더 안의 파일은 옮기거나 이름을 바꾸지 마.
```

## 3. Check before installing / 설치 전에 미리 보기

**English**

```text
Before I install anything, build a local preview of the "Drawer" folder in my synced Google Drive on this computer, and tell me which files the drawer would skip or show without a title.
```

**한국어**

```text
설치하기 전에 이 컴퓨터에 동기화된 Google Drive의 "서랍" 폴더로 로컬 미리보기를 만들어 보고, 서랍이 건너뛰거나 제목 없이 보여 줄 파일을 알려 줘.
```

## 4. Update to a new version / 새 버전으로 바꾸기

**English**

```text
There is a new version of Drive Drawer. Help me update my existing web app without changing its address.
```

**한국어**

```text
드라이브 서랍 새 버전이 나왔어. 지금 쓰는 웹앱 주소가 바뀌지 않게 업데이트하는 걸 도와줘.
```

## 5. Add a service / 서비스 추가하기

**English**

```text
I also keep Perplexity chats in a "perplexity" folder. Add it to my drawer's services, keep the four default ones, and show me the property value to paste.
```

**한국어**

```text
Perplexity 대화도 "perplexity" 폴더에 모아 두고 있어. 기본 네 서비스는 그대로 두고 서랍 서비스에 추가해 줘. 붙여 넣을 속성 값을 보여 줘.
```

## 6. Write in the drawer's format / 서랍 형식으로 글 넣기

**English**

```text
Save this paragraph from my Claude chat "Garden plan" as a piece of writing in my drawer's texts folder, with today's date and a link back to the chat.
```

**한국어**

```text
Claude 대화 「정원 계획」에서 이 문단을 서랍의 texts 폴더에 글로 저장해 줘. 날짜는 오늘로 하고, 그 대화로 돌아가는 연결도 넣어 줘.
```

## 7. Fix an error / 오류 고치기

**English**

```text
My drawer says "Could not read the Drive list (403…)". What do I change, step by step?
```

**한국어**

```text
서랍에 "Drive 목록을 읽지 못했어요 (403…)"라고 나와. 무엇을 바꿔야 하는지 하나씩 알려 줘.
```
